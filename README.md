## 🎯 About CareerMind AI

CareerMind AI is an **AI-powered career companion** built to help users
understand their career goals, identify skill gaps, prepare for opportunities,
and make better career decisions.

Instead of using different platforms for resumes, interview preparation,
career planning, learning, and job discovery, CareerMind AI brings these
workflows together into one intelligent workspace.

> **Understand your goals. Identify what you need. Build a roadmap. Prepare smarter. Move forward with confidence.**

---

## ✨ Features

### 🤖 AI Career Assistant

Get personalized career guidance based on your:

- Career goals
- Skills
- Interests
- Experience
- Target job roles

### 📄 Resume Builder

Create and improve professional resumes tailored to specific career goals
and job opportunities.

### 🔍 Resume Analysis

Analyze your resume and identify areas for improvement, including:

- Skills
- Keywords
- Structure
- Clarity
- Overall presentation

### 🎤 Interview Preparation

Practice technical and behavioral interview questions with AI-powered
guidance and feedback.

### 🧠 Skill Gap Analysis

Identify the difference between your current skills and the skills required
for your target role.

### 💼 Job Matching

Find opportunities that better match your skills, interests, and career goals.

### 📈 Career Roadmaps

Generate structured career and learning roadmaps based on your current level
and target role.

### 📚 Learning Support

Discover learning resources and courses designed to help close your
identified skill gaps.

### 🏢 Company Discovery

Explore companies and discover potential career opportunities.

### 📊 Progress Tracking

Track your learning, interview preparation, skills, and overall career
development.

## 🚀 Run Locally

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

---

## 🔐 Environment Variables

Create a `.env.local` file in the project root and add:

```env
GEMINI_API_KEY=your_gemini_api_key
```

> ⚠️ Never commit `.env.local` or expose your API key publicly.

---

## 🔒 Security

CareerMind AI uses environment variables for sensitive API configuration.

Keep credentials such as:

```text
GEMINI_API_KEY
```

private and never commit secrets to GitHub.
